# L1 公理自检 + L2 已知关系真值（rts_v2）

## 这一步在做什么

L1 查三条不需要领域知识的性质：完全相同的字段份额必须相等、恒定字段份额必须为 0、所有份额之和必须等于全部发布相比什么都不发布多出来的能力。L2 用 RTS-GMLC 数据自带的精确汇总关系当答案键，其中系统总发电有四条互不相同的精确路径。

运行目录 `run_20260815_053732`，数据集 `rts_v2`。
