## 二、引言改写

### 1. 第一段（两类关系描述）

**paper9 问题**：措辞过于教科书式和绝对化，如"决定了一个字段可以由哪些字段直接算出""意味着……仍可能被公开字段的组合高精度还原"等，读起来像是在下定义而非论述。"纽带"一词上一版已改但仍残留在部分语境中。

**改为**：以"值得关注的特征"引出，用"往往存在""许多字段之间具有""特定字段的组合仍可能"等留有余地的表述替代绝对化措辞。末句明确说"两者的区分是全文方法设计的出发点"，比原来的"全文讨论的主线"更具体。

### 2. 删除 PJM 具体引用

原第二段"美国 PJM 等市场通过数据接口对外提供大规模的运行与市场数据"及相关引用已删除，避免给读者留下"PJM 发布的数据都是公开且安全的"印象。PJM 仍在实验设置中出现（4.1 节），那里作为实验对象的身份是清楚的。

### 3. 隐性推断定义的逻辑

paper9 的结构是：先说"两类性质不同的关联"→ 再定义"隐性推断"→ 再说"隐性推断源"。"第一类""第二类"的措辞容易让人觉得这是客观既有的分类，而实际上是本文为了方法设计而做的划分。

改为：引言中先说"一方面……另一方面……"的现象描述，然后说"本文将前者称为公式关系（含近似关系），后者称为隐性推断"，明确标注这是本文的术语。2.2 节的标题从"两类还原关系"不变，但正文中不再用"第一类""第二类"，改为"一类是……另一类是……"的并列表述。3.2 节同步修改，用"可显式表达的还原关系"替代"第一类还原关系"。

### 4. 引言第二段 AI 味段落改写

"字段规模较大时，几乎总能训练出具有一定还原能力的模型"一段语言过于主观且不够精练。改为更简洁客观的表述："字段规模较大时，模型往往能达到一定的还原精度，若只给出'存在风险'的结论，既无法区分风险程度，也无法确定处置对象。"删去了原来的"可操作的做法是""闭环能否成立取决于两个条件"等展开，直接说明本文方法围绕的两个问题。

### 5. 全文语言精炼

约 30 处措辞调整，主要类型：

| 类型 | 示例 |
|---|---|
| 去绝对化 | "无法……""只能……" → "不能……""需要……" |
| 去口语 | "真正的难点" → "审查的难点" |
| 去重复 | "该形式化直接暴露了审查的困难" → "该形式化表明审查的决策对象是字段子集" |
| 去 AI 味 | "这一性质使得选中结果在很宽的阈值范围内保持不变，避免了门控类方法中常见的阈值主观性问题，这在需要向管理者解释判定依据的审查场景中尤为重要" → 拆短，删去"尤为重要"的评价语气 |
| 增客观 | "不改变网络输出，却会使门控值失去可比性" → "不改变网络输出，却使门控值失去可比性"（删"会"，更简洁） |

方法章（第 3 节）未减少篇幅，只做措辞层面的精炼。

## 四、门控网络结构示意图

3.3 节的 fig:gating 已替换为 imagegen 直接渲染的 PNG 结构图，画面参考旧论文图 3 的学术网络示意风格，展示分解式稀疏门控网络的结构：

- 左侧输入字段 x₁、x₂、…、xₚ；
- 每个输入对应三个门控因子 γ₁,ⱼ、γ₂,ⱼ、γ₃,ⱼ，乘积形成 gⱼ；
- gⱼ 与 xⱼ 相乘得到 gⱼxⱼ，再经字段组权重 ωⱼ 接入第一隐层；
- 后续为 64--32--16 三层全连接主干与输出节点。

该图仍可作为后续人工精绘时的结构参考，但当前 PDF 中插入的是已经渲染完成的成品图，而非 TikZ 或 PPT 形状占位图。
