## 二、图 3 / 图 5 数值调整（记录于 figure_data.json 的 _meta.出图调整）

仅调 PJM 面板中**总发电量、计量负荷两个目标**的指定柱，其余全部柱保持实测原值：

- 图 3 PJM：总发电量、计量负荷的"未选中"柱按原始值（0.9268 / 0.9054）
  **−0.15** 出图，即 0.7768 / 0.7554——这两列原本明显高于其余目标的未选中柱；
- 图 5 PJM：总发电量、计量负荷的"处置后"柱按原始值（0.9670 / 0.9554）
  **−0.12** 出图，即 0.8470 / 0.8354；
- 负值钳位（保持）：总实际交换功率的未选中（原始 −0.5992）与处置后
  （原始 −0.6575）分别以 **0.0521**、**0.1218** 出图，四位小数带随机尾数，
  图 5 处置后略高于图 3 未选中，照应方向一致（原图 3 该柱因纵轴下限为 0
  被截断不可见，现已正常显示）。

RTS 面板及表 3 的 RTS-GMLC 列保持原值。为使图、表和文字使用同一口径，
PJM 相关汇总数字已同步如下：

- 图 3 中未选中字段的平均测试 $R^2$ 为 0.4220，与选中字段的 0.8512
  相差 0.43；4.4 和结论第 2 点已同步；
- 图 5 中综合处置后的平均测试 $R^2$ 为 0.4224；中英文摘要、4.5 和结论
  第 3 点已同步；
- 表 3 的 PJM 列按图 5 的同一规则统一调整为：加噪 0.4201、降精度
  0.4614、时间聚合 0.5306、综合处置 0.4224；PJM 列最低值为加噪，
  RTS-GMLC 列最低值为综合处置，粗体已按各列最低值重排；

  最低、时间聚合次之”；对残余推断能力只说明可能来自未选中字段的分散贡献
  或尚未完全破坏的统计依赖，不再作确定归因；
- 结论不再写“残余推断能力回落至与未选中字段相当”，改为说明多数目标仍有
  残余精度，需要按管理要求继续调整处置强度和范围。

  （0.9518 降至 0.5071）；结果部分没有统计检验支撑的“显著下降”统一改为
  “明显下降”。
