# 20260808-02 2024 年独立复跑、门槛图、12 个目标字段的排除分析

## 动机

上一次只在 2025 年数据上做了第一类关系检测，2024 年仅用来做跨年复验。本次要做三件事：

1. 在 2024 年数据上**独立跑一遍**完整检测，看两年得到的关系清单是否一致
2. 把门槛扫描和残差分布画成图，作为回应"阈值主观设定"这条审稿意见的材料
3. 为 12 个目标字段确定各自要删掉哪些输入字段，供下一步找推断源使用

### 绘图踩的两个坑

- 中文字体（Songti SC 等）**缺少数学减号 U+2212 和除号 ÷ 的字形**，对数刻度会渲染成方框。
  解决办法是刻度改用纯文本格式（`1e-15` 这种），绕开数学排版；字体列表末尾接 DejaVu Sans 兜底。
- 残差分布图里的"空白带"最初是我按印象手工画在 1e-4 到 1e-2，**位置画错了**。
  改成由数据自动找出分布里最大的两个空隙，位置和宽度都由数据决定。

## 结果

### 一、两年独立跑的对照

| | 2025 | 2024 |
|---|---|---|
| 数据规模 | 8760 × 69 | 8784 × 69 |
| 检出关系总数 | 15 | 14 |
| 恒定字段 | 5（相同） | 5（相同） |
| 重复字段组 | 5（相同） | 5（相同） |
| 净交换账目关系 | 2.0e-15 | 3.5e-15 |
| 日前电价三分量分解 | 1.5e-08 | 2.6e-08 |
| 非同步备用恒等式 | 2.2e-05 | 8.6e-06 |
| 实时电价近似关系 | 1.9e-04 | 2.9e-04 |
| **主用备用需求 = 1.5 × 同步备用需求** | **8.6e-05** | **不存在** |

**恒等式类两年完全一致，规则型只在 2025 年出现。** 这直接证实了上次靠"跨年残差退化 450 倍"
推断出的结论——那条关系是 2025 年新引入或调整过的市场规则，不是物理决定的。

两年独立跑出同一份清单，这件事本身就是方法稳定性的证据，比单年结果有说服力。

### 二、残差分布的真实结构（更正上次的说法）

上次我说公式型和统计型的残差"差七八个数量级"，**这个说法夸大了**。把每个字段用其余全部字段
拟合后的相对残差排序，实际分成三段：

| 段 | 残差范围 | 字段数 | 性质 |
|---|---|---|---|
| 一 | 5e-15 ~ 3e-13 | 12 | 纯数值精度，精确恒等式与重复字段 |
| 二 | 1.4e-08 ~ 7.6e-05 | 9 | 含发布舍入的恒等式、规则型关系 |
| 三 | 2.5e-03 以上 | 43 | 统计关系 |

两个空隙：段一到段二跨 **4.6 个数量级**，段二到段三跨 **1.5 个数量级**。

真正用来分"公式"和"统计"的是第二个空隙，只有 1.5 个数量级（残差 7.6e-5 对 2.5e-3，差 32 倍）。
仍然清晰可辨，但不是我上次说的那么悬殊。判定门槛 1e-3 正好落在这个空隙里，这一点是成立的。

### 三、12 个目标字段的排除分析

**全局删除（所有目标通用，共 10 个）**：5 个恒定字段 + 5 组重复字段各留一个。

**剥离力度扫描**（每格是"删几个 / 剩下的线性 R²"）：

| 目标字段 | 只删精确公式 | 含高精度近似 | R²>0.999 | R²>0.99 |
|---|---|---|---|---|
| net_actual_interchange_mw | 1 / 0.9997 | 1 / 0.9997 | 10 / 0.8229 | 10 / 0.8229 |
| gross_actual_interchange_mw | 0 / 0.7535 | 0 / 0.7535 | 0 / 0.7535 | 0 / 0.7535 |
| net_sched_interchange_mw | 1 / 0.9997 | 1 / 0.9997 | 10 / 0.8225 | 10 / 0.8225 |
| total_gen | 0 / 1.0000 | 3 / 0.9985 | 3 / 0.9985 | 8 / 0.9728 |
| metered_load_mw | 0 / 1.0000 | 4 / 0.9979 | 4 / 0.9979 | 9 / 0.9612 |
| total_losses | 0 / 0.9391 | 0 / 0.9391 | 0 / 0.9391 | 0 / 0.9391 |
| congestion_price_da | 1 / 0.3008 | 1 / 0.3008 | 1 / 0.3008 | 1 / 0.3008 |
| congestion_price_rt | 0 / 0.9997 | 0 / 0.9997 | 1 / 0.4351 | 1 / 0.4351 |
| marginal_loss_price_da | 1 / 0.7849 | 1 / 0.7849 | 1 / 0.7849 | 1 / 0.7849 |
| total_lmp_da | 1 / 0.9300 | 1 / 0.9300 | 1 / 0.9300 | 1 / 0.9300 |
| da_as_total_mw_primary_reserve | 1 / 0.7045 | 1 / 0.7045 | 1 / 0.7045 | 1 / 0.7045 |
| da_as_total_mw_thirty_minutes_reserve | 0 / 0.7677 | 0 / 0.7677 | 0 / 0.7677 | 0 / 0.7677 |

注：线性 R² 是同一份数据内拟合的结果，是可学到程度的上界，用作快速筛查。真正的评估在第 3 步用神经网络做。

**发现的两件事**：

1. **总发电量和计量负荷是互推的**，删掉的正是对方和其它负荷口径字段。这是功率平衡关系的
   统计版本——教科书公式因口径不一致而不精确成立（上次实测残差 0.498），但统计上高度可推。
   它落在"精确公式"和"统计关系"的灰区里，严格门槛剥离不掉，宽松门槛才行。
2. **实时阻塞价几乎完全由实时总电价决定**：删掉 `total_lmp_rt` 一个字段，R² 从 0.9997 掉到 0.4351。

### 四、两个目标字段本身就是重复字段

`da_as_total_mw_primary_reserve` 和 `da_as_total_mw_thirty_minutes_reserve` 各自有一个逐点完全
相同的孪生列（`da_as_as_mw_*`）。如果不删孪生列，这两个目标的 R² 会是 1.0，实验结果没有意义。

删掉孪生列后分别是 0.7045 和 0.7677。

## 对论文的影响

- 两年独立复跑的一致性可以直接写进论文，作为方法稳定性的证据
- 恒等式与规则型的区分从"靠判据推断"变成了"两年清单直接对照"，论证更硬
- 残差分布图和门槛扫描图是回应"阈值主观"最直接的材料
- 发现两个目标字段有孪生列，是方法实用价值的一个具体例证：不做这一步，实验设置本身就是错的
