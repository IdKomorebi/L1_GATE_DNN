# 20260808-06 多指标初筛重做：修正指标算法，用置换检验定阈值

但在删掉之前得先把它做对——现在的实现有真实的算法缺陷，如果保留就必须修，

同时初筛只依赖"目标字段 vs 单个候选字段"的两两关系，不涉及候选池要不要排除其余

## 一、原实现的三处问题

原代码在 `NEW_PROJECT/src/relation_analyzer.py`。

### 1. HSIC 的核宽度写死成 1，结果只反映字段量纲，不反映依赖强度

原实现：

```python
K = np.exp(-((x2 - x2.T) ** 2))     # 核宽度固定，且变量未标准化
```

高斯核里的指数项是"两点距离的平方除以核宽度"。核宽度固定成 1，而变量没有标准化，
于是字段量纲一大，指数项就下溢成 0，核矩阵退化成单位阵；量纲一小，核矩阵又几乎全是 1。
两种情况算出来的都不是依赖强度。

**实测验证**：取同一对相关系数 0.96 的变量，只改量纲：

| 量纲乘以 | 旧实现算出的 HSIC |
|---|---|
| 0.01 | 0.9256 |
| 0.1 | 0.9251 |
| 1 | 0.8237 |
| 10 | **0.2124** |
| 100 | 0.3287 |
| 1000 | 0.8272 |

作为对照，Pearson 在同样的变换下恒为 0.9621。

而真实字段的量纲跨度极大——总发电量的典型两点距离平方是 6.1e+08，燃煤占比是 2.5e-03，
**差了 11 个数量级**。所以原论文表 2 里 HSIC 那一列（有的 0.856、有的 0.032）
基本是量纲的产物。

**改法**：变量先标准化，核宽度改用"两两距离的中位数"（这是核方法里的惯用做法）。

### 2. 归一化互信息把两种不同的估计方式混用

原实现用 k 近邻法估互信息（针对连续变量），用 20 格等宽直方图估熵（针对离散变量），
然后相除。两者不在同一尺度上，相除得到的数没有明确含义；而且直方图熵还随格子数变化，
格子越多熵越大，比值就越小。原代码还把结果强行截断到 [0,1]，把问题盖住了。

**改法**：互信息和熵都用同一套**等频分箱**估计，口径一致。等频分箱（按分位数切）
比等宽分箱更适合电力数据——很多字段分布偏斜，等宽分箱会把绝大多数样本挤进一两格里。
等频分箱还顺带让结果不受量纲影响。

### 3. 阈值靠人工指定，没有依据

原来是 NMI 0.06、Spearman 0.15、Pearson 0.15、Kendall 0.12、距离相关 0.20、HSIC 0.25。
这正是审稿人二提的"阈值设置缺乏客观寻优依据"。

**改法**：用**分块置换**构造"字段与目标之间没有真实关系"时各指标的取值分布，
取 95% 分位数作为阈值。

为什么要分块而不是逐点打乱：电力数据前后小时高度相似（相邻小时相关系数 0.971）。
逐点打乱会把这个时间结构彻底破坏，得到的零分布过于集中在 0 附近，阈值定得过低，
几乎什么字段都能通过，检验就失效了。按周（168 小时）整段重排，能保住序列自身的
时间结构，只切断它与候选字段的对应关系。

## 二、做法

对每个目标字段：

1. 候选池 = 全部字段 − 目标自身 − 数据质量问题字段（5 个恒定 + 5 个重复副本）= 58 个
2. 置换 120 次，每次抽一个真实字段、把目标按周整段打乱，算六个指标 → 零分布
3. 阈值 = 零分布的 95% 分位数
4. 算每个候选字段的六个指标，**任一指标过阈值即保留**（宽松规则，初筛只负责去掉
   明显无关的，真正的取舍交给后面的门控模型）

指标全部取绝对值，负相关同样算数。

## 三、结果

### 筛选量

| 目标字段 | 候选 | 保留 | 筛除 |
|---|---|---|---|
| 净计划交换功率 | 58 | 38 | 20 |
| 净实际交换功率 | 58 | 39 | 19 |
| 日前主用备用总量 | 58 | 39 | 19 |
| 计量负荷 | 58 | 41 | 17 |
| 总发电量 | 58 | 42 | 16 |
| 日前30分钟备用总量 | 58 | 42 | 16 |
| 日前边际损耗价 | 58 | 43 | 15 |
| 日前总电价 | 58 | 44 | 14 |
| 总网损 | 58 | 46 | 12 |
| 实时阻塞价 | 58 | 46 | 12 |
| 总实际交换功率 | 58 | 47 | 11 |
| 日前阻塞价 | 58 | 47 | 11 |

**平均筛除 15.2 个字段，占 26.1%。** 强度合适——去掉了明显无关的四分之一，
又没有把可能有互补作用的字段过早剔除。

### 本方法定出的阈值 vs 原项目人工指定的

| 指标 | 本方法（12 个目标的均值） | 原项目 |
|---|---|---|
| Pearson | 0.172 | 0.150 |
| Spearman | 0.198 | 0.150 |
| Kendall | 0.141 | 0.120 |
| 距离相关 | 0.200 | 0.200 |
| 归一化互信息 | 0.029 | 0.060 |
| **HSIC** | **0.031** | **0.250** |

前四个相当接近，说明当初凭经验猜的数量级是对的（也侧面印证了置换检验给出的
阈值是合理的）。后两个差得很远：

- HSIC 差了 8 倍。原因是旧实现的 HSIC 数值本身就被量纲主导，那个 0.25 的阈值
  和修正后的取值不在一个尺度上，没有可比性。
- 归一化互信息原来定 0.06，比修正后的 0.029 严一倍，会误筛一部分字段。

**另一个好处：阈值现在随目标字段自动变化。** 比如总发电量的 Pearson 阈值是 0.249，
日前阻塞价是 0.103——因为两者的自相关强弱不同，"多大的相关算是巧合"本来就不一样。
人工指定一个固定值做不到这一点。

### 六类指标之间的重复度

`fig_metric_agreement.png` 给出两两之间对"该保留哪些字段"的判断吻合度：

| | Pearson | Spearman | Kendall | 互信息 | 距离相关 | HSIC |
|---|---|---|---|---|---|---|
| Pearson | 1.00 | 0.77 | 0.75 | 0.72 | 0.86 | 0.73 |
| Spearman | | 1.00 | **0.95** | 0.66 | 0.82 | 0.79 |
| Kendall | | | 1.00 | 0.65 | 0.80 | 0.78 |
| 互信息 | | | | 1.00 | 0.72 | 0.73 |
| 距离相关 | | | | | 1.00 | 0.83 |
| HSIC | | | | | | 1.00 |

两点值得注意：

- **Spearman 和 Kendall 吻合度 0.95，几乎完全重复。** 两者都是秩相关，本来就测同一件事。
  如果要压缩篇幅，这两个留一个就够。
- **归一化互信息与其余指标的吻合度最低（0.65–0.73），提供的独立信息最多。**
  如果只保留三个指标，Pearson（线性）+ 距离相关或 HSIC（非线性）+ 互信息（信息论角度）
  是覆盖面最好的组合。

### 通过指标数的分布呈明显两极

12 个目标合计（58×12 = 696 个字段-目标对）：

| 通过几个指标 | 字段计数 |
|---|---|
| 0 个 | 182 |
| 1 个 | 59 |
| 2 个 | 41 |
| 3 个 | 37 |
| 4 个 | 42 |
| 5 个 | 54 |
| **6 个全通过** | **280** |

**两头大、中间小**：要么六个指标全不通过（182），要么六个全通过（280），
中间状态加起来才 233。说明字段是否与目标相关，在这批数据上是个相当清楚的二分，
不是连续过渡。这也解释了为什么"任一通过即保留"这条宽松规则不会导致保留过多——
真正处在边界上的字段并不多。

## 五、对论文的意义

如果保留初筛这一节，它现在能同时回应两条审稿意见：

- **阈值主观**（审稿人二第 3 条）：阈值由置换检验给出，随目标字段自动变化，
  且与人工猜测的数量级吻合
- **方法细节的严谨性**：HSIC 和互信息的算法缺陷已修正，并有实测证据说明为什么要修

如果删掉这一节，也应该在方法部分说明"初筛不是必需环节"——因为 8760 行 × 58 列的
规模下，全部字段直接进门控模型在计算上毫无压力，初筛的作用主要是可解释性
（说明选中字段呈现哪种依赖类型），而不是降低计算量。
