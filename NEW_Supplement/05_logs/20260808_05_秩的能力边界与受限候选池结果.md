# 20260808-05 求秩这套工具的能力边界（含对上一份日志的更正），以及受限候选池下的剥离结果

## 一、对 `20260808_04` 的更正

上一份日志第四节写了"用去掉字段前后的方向数之差，可以数出有几条独立关系涉及该字段"，
并据此得出"总发电量只有 1 条独立关系、12 层都是同一条关系的变形"。

**这个结论是错的，而且错在数学上，不是数值精度问题。**

### 为什么差值只能是 0 或 1

把"所有能让字段加权相加等于零的系数组合"看成一个集合，它有维数——维数是几，就是有几条互相
独立的关系。

盯住某个字段 T，按"T 位置上的系数是不是零"把这些组合分两类：

- T 的系数是零：不涉及 T，删掉 T 之后照样成立
- T 的系数不是零：涉及 T

关键在于：**任意两条涉及 T 的关系，缩放之后相减就能把 T 消掉，变成一条不涉及 T 的关系。**
比如甲里 T 的系数是 2、乙里是 3，那么 3×甲 − 2×乙 里 T 的系数就是 0。

这意味着"涉及 T"这件事在维数上最多只能贡献 1。所以

```
去掉 T 之后的维数 = 原来的维数 − (0 或 1)
```

**永远不会是 2 或更多。** 那张全是 0 和 1 的表不是数据的性质，是被数学锁死的。它只能回答
"T 参不参与关系"这个是非题，数不出条数。

### 实测里出现过 2，那是数值假象

随机抽 30 组各 12 个字段逐个算差值，出现过 0、1、2。这不是反例：

我数的不是"严格等于零的方向"，而是"小于某个门槛的方向"。删掉一列之后，**整条奇异值序列都会
平移**，不只是少一个，所以在松门槛下跨过门槛的个数可以变化不止 1。这个 2 不代表"有两条关系"，
不能当计数用。

紧门槛下（真正在量秩亏）严格是 0/1；松门槛下大于 1 但没有计数含义。两种情况都数不出条数。

### 那"某字段有几条推断路径"该怎么求

这个量在数学上根本不是"维数"，所以求秩这条路走不通。它是**组合枚举问题**——有多少个互不相同
的最小字段组能推出该目标——数量可能随字段数指数增长，只能一个个找。

## 二、求秩这套工具的能力边界（结论汇总）

| 问题 | 能否回答 | 说明 |
|---|---|---|
| 整张表里一共有几条独立关系 | **能** | 就是维数。1e-5 门槛下 5 条，1e-3 下 9 条，1e-2 下 23 条，1e-1 下 47 条 |
| 各精度区间里各有几条 | **能** | 相邻门槛相减。1e-5 以内 5 条、1e-5~1e-3 有 4 条、1e-3~1e-2 有 14 条、1e-2~1e-1 有 24 条 |
| 第 2 步全局提取的精确关系找全了没有 | **能，且是严格验证** | 秩亏说该有 15 条，化简加补足正好写出 15 条。这个对账已经写在 `extract()` 里 |
| 某字段参不参与关系 | **能，但只有是/否** | 见上一节 |
| 某字段参与了几条关系 | **不能** | 这个量在数学上没有维数意义 |
| 某字段有几条推断路径 | **不能** | 组合枚举问题，只能逐个找 |
| 逐层剥离该挖几层 | **不能** | 没有独立的线性代数手段能给出对照 |

### 一个必须记住的刻度问题

奇异值比是对**整个矩阵**（列已归一化）算的，字段相对残差是对**单个字段**归一化的，
两者不是同一把尺子。所以"按奇异值分的档"和"按字段残差分的档"只能作量级参照，不能一一对应。

已经踩过这个坑：日前电价三分量的字段残差是 1.5e-08，但它对应的奇异值比大于 1e-08，
在 1e-08 的秩门槛下没被算进去。

### 结论

求秩仍然有不可替代的作用——**它是唯一能独立回答"全局该有几条精确关系"的工具**，
第 2 步的完整性靠它验证。但它对逐层剥离的层数没有发言权，那部分只能靠枚举，或者暂时没有对照。

## 三、停止判据的澄清

前面几轮讨论绕了弯路，这里定论：

**判据就是"目标还能不能被剩下的字段线性表示"**，这一条从一开始就在用，写在
`02d_layered_strip.py` 的循环里：

```
每一层：
  ① 用当前剩下的全部字段做线性回归拟合目标   ← 线性表示强度
  ② 强度不够（残差 ≥ 0.10，即 R² < 0.99）就停
  ③ 强度够 → 反向消元找最小字段组
  ④ 删掉其中贡献最大的一个，进入下一层
```

R² 随层数下降的轨迹（未受限候选池）：

| 目标 | 轨迹 |
|---|---|
| 净实际交换 | 0.9981 → 0.9981 → 0.9300 停 |
| 净计划交换 | 0.9981 → 0.9981 → 0.9981 → 0.9297 停 |
| 总发电量 | 1.0000×4 → 0.9984×3 → 0.9977 → 0.9967 → 0.9933 → 0.9932 → 0.9748 停 |
| 计量负荷 | 0.9999×4 → 0.9983×3 → 0.9979 → 0.9964 → 0.9928 → 0.9927 → 0.9733 停 |

另外两个额外做过的检验，结论如下，都不作为停止判据：

- **跨时段稳定性**（按时间分 5 块轮流验算，看误差放大倍数）：36 层放大倍数中位数 1.24、
  最大 1.62，一层都筛不掉。原因是当前每层最多用 16 个字段拟合 8760 个样本，不存在过拟合，
  也就没有伪关系可抓。保留它作为安全网，将来扩展到高次项或分季度分析时会起作用。
- **与随机字段的强度对照**（同样数量的随机字段能拟合到什么程度）：36 层全部比随机强
  3.8 倍以上，也筛不掉。但它显出了断崖——总发电量和计量负荷在第 5→6 层，强度从
  59/68 倍掉到 4.3/6.4 倍，掉了一个数量级。这个断崖可以作为分档依据。

### 一个很清晰的模式：非线性的额外增益大多是假的

把"GBDT 相对线性的增益"和"时序划分下的表现"放在一起看：

| 目标 | 随机划分下 GBDT 比线性高多少 | 时序划分下 GBDT |
|---|---|---|
| 日前阻塞价 | **+0.50** | −0.08 崩 |
| 日前30分钟备用总量 | **+0.17** | −0.22 崩 |
| 日前边际损耗价 | **+0.14** | 0.48 掉一半 |
| 总实际交换功率 | **+0.13** | −0.27 崩 |
| 总网损 | +0.03 | 0.67 |
| 计量负荷 | −0.00 | 0.9999 稳 |
| 总发电量 | −0.00 | 0.9675 稳 |
| 日前主用备用总量 | −0.00 | 0.9820 稳 |
| 日前总电价 | −0.01 | 0.9527 稳 |
| 实时阻塞价 | −0.31 | 0.5052 |

**规律：随机划分下 GBDT 大幅超过线性的那几个目标，在时序划分下全部崩溃；
而线性就能推准的那几个，换成时序划分依然稳。**

这说明 GBDT 那部分"额外增益"主要来自记住相邻时段的样本模式（随机划分把测试样本夹在训练样本
的前后小时之间），不是真实存在的推断关系。而线性能推的部分是跨时段稳定的。

对下一步的直接含义：**真正的推断风险集中在线性稳定可推的那几个目标**——计量负荷、
日前主用备用总量、总发电量、日前总电价。它们在两种模型、两种划分下都保持 0.95 以上。

其余目标即使随机划分下 GBDT 能推到 0.88–0.91，也不构成可靠的推断风险，因为换个时间段就失效。
