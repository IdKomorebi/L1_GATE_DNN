# 各方法总体比较（rule1）

候选池：排除其余关注字段　｜筛选设定：with_screening

## 一、对比规则

每个目标字段的**统一预算 n 由本文方法定**——D-Gating 的门控值分布有断崖，被淘汰的字段直接落到机器零，阈值在五个数量级之间取任何值都得到同一个 n，所以这个 n 不依赖人工设定。其余方法按自己的排序取前 n 个，统一用同一个普通 DNN 训练测试。
