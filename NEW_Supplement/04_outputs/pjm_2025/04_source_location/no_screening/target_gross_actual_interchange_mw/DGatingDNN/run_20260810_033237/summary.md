运行时间 20260810_033237　方法 **DGatingDNN**

## 一、这次跑的是什么

- 目标字段：`gross_actual_interchange_mw`（总实际交换功率）
- 数据：pjm_2025，8760 行
- 候选字段：**58 个**（未做额外限制）
- 网络结构：64-32-16，训练 200 轮，批大小 50，学习率 0.001
- 数据划分：随机 80% 训练 / 20% 测试，随机种子 42

## 二、结论先看这里

- 从 58 个候选字段里选出 **22 个**推断源（占 37.9%）
- 只用这 22 个字段重新训练普通 DNN，测试 R² = **0.8814**
- 作为对照，用全部 58 个字段的普通 DNN 测试 R² = 0.8739
- 没被选中的 36 个字段单独训练，测试 R² = 0.6390

> 用 38% 的字段达到了和全量相当的精度（相差 +0.0075），说明这组字段确实承载了推断目标所需的主要信息。
