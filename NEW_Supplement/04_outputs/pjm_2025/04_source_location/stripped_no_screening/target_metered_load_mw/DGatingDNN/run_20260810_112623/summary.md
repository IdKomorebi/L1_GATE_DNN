# 推断源定位：计量负荷

运行时间 20260810_112623　方法 **DGatingDNN**

## 一、这次跑的是什么

- 目标字段：`metered_load_mw`（计量负荷）
- 数据：pjm_2025，8760 行
- 候选字段：**46 个**（剥离第一类关系（12 个字段））
- 网络结构：64-32-16，训练 200 轮，批大小 50，学习率 0.001
- 数据划分：随机 80% 训练 / 20% 测试，随机种子 42

## 二、结论先看这里

- 从 46 个候选字段里选出 **7 个**推断源（占 15.2%）
- 只用这 7 个字段重新训练普通 DNN，测试 R² = **0.9905**
- 作为对照，用全部 46 个字段的普通 DNN 测试 R² = 0.9947
- 没被选中的 39 个字段单独训练，测试 R² = 0.9825

> 用 15% 的字段达到了和全量相当的精度（相差 -0.0043），说明这组字段确实承载了推断目标所需的主要信息。
