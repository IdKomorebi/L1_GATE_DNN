# 第一类关系剥离过程：净计划交换功率

候选池设定：含其余关注字段

## 一、这个目标一共有 4 层关系

按误差量级归档：

- 近似关系：4 层

档次的划分标准：精确公式（相对残差 < 1e-6）、含舍入的公式（1e-6 ~ 1e-3）、
高精度近似（1e-3 ~ 3e-2）、近似关系（3e-2 ~ 1e-1）。
相对残差 = 拟合剩下的误差 ÷ 该目标字段自身的波动幅度。

## 二、一层一层是怎么挖出来的

每一层的做法：用当时还剩下的全部字段拟合目标，再从全字段出发逐个删掉贡献最小的，缩到最小的一组；
然后只删掉这组里贡献最大的那**一个**字段，进入下一层看还能不能再找出关系。
只删一个而不是整组删掉，是为了让剩下的字段有机会自己凑出新路径，这样才挖得深。

### 第 1 层　[近似关系]　相对残差 3.58e-02（相当于 R² = 0.9987）

```
net_sched_interchange_mw = +0.998*net_actual_interchange_mw -38.82
```

- 这条关系用到 1 个字段
- **删掉贡献最大的 `net_actual_interchange_mw`（净实际交换）**
- 删完之后候选池剩 57 个字段，目标仍能被线性回归推到 R² = **0.9981**

### 第 2 层　[近似关系]　相对残差 4.29e-02（相当于 R² = 0.9982）

```
net_sched_interchange_mw = -0.9982*total_gen +0.9992*metered_load_mw -81.1*da_as_as_req_mw_primary_reserve +121.6*da_as_as_req_mw_synchronized_reserve -141.9*da_as_as_mw_primary_reserve +141.9*da_as_as_mw_synchronized_reserve +141.9*da_as_nsr_mw_primary_reserve -7900
```

- 这条关系用到 7 个字段
- **删掉贡献最大的 `da_as_nsr_mw_primary_reserve`（非同步备用）**
- 删完之后候选池剩 56 个字段，目标仍能被线性回归推到 R² = **0.9981**

### 第 3 层　[近似关系]　相对残差 4.29e-02（相当于 R² = 0.9982）

```
net_sched_interchange_mw = -0.9981*total_gen +0.9991*metered_load_mw -99.45*da_as_as_req_mw_primary_reserve +149.2*da_as_as_req_mw_synchronized_reserve -9640
```

- 这条关系用到 4 个字段
- **删掉贡献最大的 `da_as_as_req_mw_synchronized_reserve`（日前同步备用需求）**
- 删完之后候选池剩 55 个字段，目标仍能被线性回归推到 R² = **0.9981**

### 第 4 层　[近似关系]　相对残差 4.30e-02（相当于 R² = 0.9982）

```
net_sched_interchange_mw = -0.997*total_gen +0.9981*metered_load_mw -167.5
```

- 这条关系用到 2 个字段
- **删掉贡献最大的 `total_gen`（总发电量）**
- 删完之后候选池剩 54 个字段，目标仍能被线性回归推到 R² = **0.9297**

## 三、最终从候选池里剥掉了这些字段

| 层 | 字段 | 业务含义 | 剥离后线性 R² |
|---|---|---|---|
| 1 | `net_actual_interchange_mw` | 净实际交换 | 0.9981 |
| 2 | `da_as_nsr_mw_primary_reserve` | 非同步备用 | 0.9981 |
| 3 | `da_as_as_req_mw_synchronized_reserve` | 日前同步备用需求 | 0.9981 |
| 4 | `total_gen` | 总发电量 | 0.9297 |

候选池：**58 → 54 个字段**（实际剥掉 4 个）。

## 四、为什么必须先做这一步

这些关系有公式可循，属于已知的、可以靠规则枚举禁止的风险，不是本文要找的隐性推断源。
如果不剥离就直接跑门控模型，模型一定优先选中这些字段——因为它们推断得最准——
真正没有公式可循的推断路径就被完全盖住了。

剥离之后目标仍能被推到 R² = 0.9297，**这部分才是隐性推断的部分**。
