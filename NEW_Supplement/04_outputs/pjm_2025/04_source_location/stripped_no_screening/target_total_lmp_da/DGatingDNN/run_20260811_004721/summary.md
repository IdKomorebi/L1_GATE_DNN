# 推断源定位：日前总电价

运行时间 20260811_004721　方法 **DGatingDNN**

## 一、这次跑的是什么

- 目标字段：`total_lmp_da`（日前总电价）
- 数据：pjm_2025，8760 行
- 候选字段：**57 个**（剥离第一类关系（1 个字段））
- 网络结构：64-32-16，训练 200 轮，批大小 50，学习率 0.001
- 数据划分：随机 80% 训练 / 20% 测试，随机种子 42

## 二、结论先看这里

- 从 57 个候选字段里选出 **12 个**推断源（占 21.1%）
- 只用这 12 个字段重新训练普通 DNN，测试 R² = **0.9740**
- 作为对照，用全部 57 个字段的普通 DNN 测试 R² = 0.9756
- 没被选中的 45 个字段单独训练，测试 R² = 0.9512

> 用 21% 的字段达到了和全量相当的精度（相差 -0.0016），说明这组字段确实承载了推断目标所需的主要信息。
