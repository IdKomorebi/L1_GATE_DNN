## 一、这次跑的是什么

- 目标字段：`da_as_total_mw_thirty_minutes_reserve`（日前30分钟备用总量）
- 数据：pjm_2025，8760 行
- 候选字段：**36 个**（排除其余关注字段；剥离第一类关系（已知公式 0 个 + 数据发现 0 个）；经过多指标初筛）
- 网络结构：64-32-16，训练 200 轮，批大小 50，学习率 0.001
- 数据划分：随机 80% 训练 / 20% 测试，随机种子 42

## 二、结论先看这里

- 从 36 个候选字段里选出 **14 个**推断源（占 38.9%）
- 只用这 14 个字段重新训练普通 DNN，测试 R² = **0.8961**
- 作为对照，用全部 36 个字段的普通 DNN 测试 R² = 0.8971
- 没被选中的 22 个字段单独训练，测试 R² = 0.8429

> 用 39% 的字段达到了和全量相当的精度（相差 -0.0011），说明这组字段确实承载了推断目标所需的主要信息。
