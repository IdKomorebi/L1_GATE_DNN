# 推断源定位：计量负荷

运行时间 20260812_013635　方法 **DGatingDNN**

## 一、这次跑的是什么

- 目标字段：`metered_load_mw`（计量负荷）
- 数据：pjm_2025，8760 行
- 候选字段：**31 个**（排除其余关注字段；剥离第一类关系（已知公式 0 个 + 数据发现 6 个）；经过多指标初筛）
- 网络结构：64-32-16，训练 200 轮，批大小 50，学习率 0.001
- 数据划分：随机 80% 训练 / 20% 测试，随机种子 42

## 二、结论先看这里

- 从 31 个候选字段里选出 **3 个**推断源（占 9.7%）
- 只用这 3 个字段重新训练普通 DNN，测试 R² = **0.9864**
- 作为对照，用全部 31 个字段的普通 DNN 测试 R² = 0.9953
- 没被选中的 28 个字段单独训练，测试 R² = 0.9943

> 用 10% 的字段达到了和全量相当的精度（相差 -0.0089），说明这组字段确实承载了推断目标所需的主要信息。
