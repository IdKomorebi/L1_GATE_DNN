# 推断源定位：实时阻塞价

运行时间 20260812_021034　方法 **DGatingDNN**

## 一、这次跑的是什么

- 目标字段：`congestion_price_rt`（实时阻塞价）
- 数据：pjm_2025，8760 行
- 候选字段：**34 个**（排除其余关注字段；剥离第一类关系（已知公式 3 个 + 数据发现 0 个）；经过多指标初筛）
- 网络结构：64-32-16，训练 200 轮，批大小 50，学习率 0.001
- 数据划分：随机 80% 训练 / 20% 测试，随机种子 42

## 二、结论先看这里

- 从 34 个候选字段里选出 **18 个**推断源（占 52.9%）
- 只用这 18 个字段重新训练普通 DNN，测试 R² = **0.4173**
- 作为对照，用全部 34 个字段的普通 DNN 测试 R² = 0.4080
- 没被选中的 16 个字段单独训练，测试 R² = 0.4077

> 用 53% 的字段达到了和全量相当的精度（相差 +0.0093），说明这组字段确实承载了推断目标所需的主要信息。
