- 目标字段：`da_as_total_mw_thirty_minutes_reserve`（日前30分钟备用总量）
- 数据：pjm_2025，8760 行
- 候选字段：**48 个**（排除其余关注字段；剥离第一类关系（已知公式 0 个 + 数据发现 0 个））

- 数据划分：随机 80% 训练 / 20% 测试，随机种子 42

## 二、结论先看这里

- 从 48 个候选字段里选出 **16 个**推断源（占 33.3%）
- 只用这 16 个字段重新训练普通 DNN，测试 R² = **0.9029**
- 作为对照，用全部 48 个字段的普通 DNN 测试 R² = 0.8949
- 没被选中的 32 个字段单独训练，测试 R² = 0.8467

> 用 33% 的字段达到了和全量相当的精度（相差 +0.0080），说明这组字段确实承载了推断目标所需的主要信息。
