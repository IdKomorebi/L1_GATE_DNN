# 推断源定位：净实际交换功率

运行时间 20260812_004958　方法 **DGatingDNN**

## 一、这次跑的是什么

- 目标字段：`net_actual_interchange_mw`（净实际交换功率）
- 数据：pjm_2025，8760 行
- 候选字段：**48 个**（排除其余关注字段；剥离第一类关系（已知公式 1 个 + 数据发现 0 个））
- 网络结构：64-32-16，训练 200 轮，批大小 50，学习率 0.001
- 数据划分：随机 80% 训练 / 20% 测试，随机种子 42

## 二、结论先看这里

- 从 48 个候选字段里选出 **11 个**推断源（占 22.9%）
- 只用这 11 个字段重新训练普通 DNN，测试 R² = **0.9605**
- 作为对照，用全部 48 个字段的普通 DNN 测试 R² = 0.9673
- 没被选中的 37 个字段单独训练，测试 R² = 0.8861

> 用 23% 的字段达到了和全量相当的精度（相差 -0.0068），说明这组字段确实承载了推断目标所需的主要信息。
