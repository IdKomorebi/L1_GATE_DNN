# 第一类关系剥离过程：总发电量

候选池设定：排除其余关注字段

剥离分两层：**第一层按已知公式，不看残差**；第二层按数据发现的关系逐层剥离。

## 第一层：按已知公式剥离

该目标命中了这几条已知公式：分燃料出力求和、功率平衡

因此剔除以下字段（依据是官方文档与电力常识，不需要任何阈值）：

| 字段 | 业务含义 |
|---|---|
| `gen_fuel_coal_mw` | 燃煤出力 |
| `gen_fuel_gas_mw` | 燃气出力 |
| `gen_fuel_hydro_mw` | 水电出力 |
| `gen_fuel_multiple_fuels_mw` | 多燃料出力 |
| `gen_fuel_nuclear_mw` | 核电出力 |
| `gen_fuel_oil_mw` | 燃油出力 |
| `gen_fuel_other_renewables_mw` | 其他可再生出力 |
| `gen_fuel_solar_mw` | 光伏出力 |
| `gen_fuel_storage_mw` | 储能出力 |
| `gen_fuel_wind_mw` | 风电出力 |

这一层堵的是这样一个漏洞：某些公式分量在当前候选池里的残差可能刚好高于按残差剥离的门槛而漏过去（例如日前总电价的 `总电价 ≈ 能量价格` 残差 0.116，高于门槛 0.10），导致「剥离之后」仍能被一两个字段推得很准。

## 第二层：按数据发现的关系逐层剥离

## 一、这个目标一共有 5 层关系

按误差量级归档：

- 近似关系：5 层

档次的划分标准：精确公式（相对残差 < 1e-6）、含舍入的公式（1e-6 ~ 1e-3）、
高精度近似（1e-3 ~ 3e-2）、近似关系（3e-2 ~ 1e-1）。
相对残差 = 拟合剩下的误差 ÷ 该目标字段自身的波动幅度。

## 二、一层一层是怎么挖出来的

每一层的做法：用当时还剩下的全部字段拟合目标，再从全字段出发逐个删掉贡献最小的，缩到最小的一组；
然后只删掉这组里贡献最大的那**一个**字段，进入下一层看还能不能再找出关系。
只删一个而不是整组删掉，是为了让剩下的字段有机会自己凑出新路径，这样才挖得深。

## 四、为什么必须先做这一步

这些关系有公式可循，属于已知的、可以靠规则枚举禁止的风险，不是本文要找的隐性推断源。
如果不剥离就直接跑门控模型，模型一定优先选中这些字段——因为它们推断得最准——
真正没有公式可循的推断路径就被完全盖住了。

剥离之后目标仍能被推到 R² = 0.9862，**这部分才是隐性推断的部分**。
