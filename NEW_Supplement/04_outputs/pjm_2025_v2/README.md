# pjm_2025_v2：重跑版本

与 `pjm_2025` 并列。**该目录目前只有说明与方案，尚未执行任何实验。**

## 为什么要重跑

`pjm_2025` 里的结果暴露出两个问题，都不是实现 bug，而是设定不当，
但影响到方法的核心主张，必须重跑才能纠正。

### 问题一：剥离门槛太松，公式关系漏了过去

现在的剥离只有一层，按"目标能否被剩余字段以残差 0.10 以内算出"来判断。
日前总电价这个目标暴露了它的漏洞：

- 电价分解公式 `总电价 = 能量价格 + 阻塞价 + 网损价` 是 PJM 官方文档写明的
- 阻塞价和网损价都是受关注字段、已被排除，只剩能量价格
- 剩下这条 `总电价 ≈ 能量价格` 的残差是 **0.116**，刚好高于门槛 0.10
- 于是它没被剥离，导致"剥离之后"仍有 **1 个字段就能推到 R² = 0.9865**

单纯把门槛从 0.10 调到 0.15 不是好办法——那只是把界线往外挪，
下次还会有别的关系卡在新界线边上，而且新的界线同样没有依据。

### 问题二：初筛的分位数取错了方向

阈值取的是零分布的 **95% 分位**——这是照搬统计检验的惯例，而那个惯例控制的是**误报率**。
但初筛这一步要控制的是**漏报率**：方法里写明的设计目标就是"宁可多留弱冗余字段，
也不在早期排除可能有互补作用的字段"。留错了后面的门控会关掉它，代价很小；
漏掉了就永远找不回来。**既然要防漏，就不该用一个控制误报的分位数。**

后果在净实际交换功率上很明显：

| 被初筛砍掉的字段 | \|Pearson\| | 通过指标数 | 单独加回后 R² |
|---|---|---|---|
| **预估小时负荷** | **0.1063** | **0 / 6** | **0.9020 → 0.9613** |
| 实时负荷电量 | 0.1100 | 0 / 6 | → 0.9593 |
| 最新负荷预测 | 0.1108 | 0 / 6 | → 0.9208 |

预估小时负荷与目标的相关系数只有 0.106，六项指标一项都没过，
但加回它一个就能把 R² 拉高 0.059。原因是净交换的功率平衡关系
`净实际交换 = 计量负荷 − 总发电量` 里，它是计量负荷的替身——
差值关系让两两相关性被抵消掉，单看几乎无关，组合起来却是决定性的。

**改成 90% 分位**：三个关键字段全部保住，平均筛除率从 26.1% 降到 18.2%，初筛仍然有效。

需要如实写进局限性的一点：燃油占比的零分布分位是 93.3%，**比这三个有用字段都高，
但它加进去反而让 R² 降了 0.006**。说明"零分布分位"这个排序根本不能区分有用与无用——
它衡量的是"两两关系有多不像巧合"，不是"在组合推断里值不值钱"。
**任何基于两两关系的阈值都有这个天花板**，降到 90% 只是缓解了这个具体案例，有运气成分。
彻底的解法是把初筛并进门控（不删字段、只提供相关系数作为特征），由推断误差决定取舍。

### 问题三：稀疏强度太弱，选出的字段偏多而精度没有提升

现在 λ = 0.002。四个目标上的实测（排除关注字段、已剥离）：

| λ | 平均选中字段数 | 平均测试 R² |
|---|---|---|
| **0.002（现用）** | **16.50** | **0.8675** |
| 0.004 | 12.50 | 0.8878 |
| **0.005** | **11.25** | **0.8879** |
| 0.006 | 10.50 | 0.8839 |
| 0.007 | 10.25 | 0.8850 |
| 0.008 | 9.25 | 0.8796 |
| 对照 STG | 12.50 | 0.8766 |

λ = 0.002 是最差的一档：字段最多（16.5）而精度最低（0.8675）。
其中日前阻塞价尤其明显，λ=0.002 时 R² 只有 0.6518，λ=0.005 时是 0.7425，
差 0.09——说明 λ 太小时训练欠收敛，不是方法本身的问题。

## 与 pjm_2025 的差别

| | pjm_2025 | **pjm_2025_v2** |
|---|---|---|
| 剥离方式 | 单层，按残差 0.10 | **两层：先按已知公式剥离（不看残差），再按残差剥离** |
| 初筛阈值分位数 | 95%（控误报） | **90%（控漏报）** |
| D-Gating 稀疏系数 λ | 0.002 | **0.005** |
| 跑哪几组 | 含/排除关注字段 × 未筛/已筛，共 4 组 | **只跑排除关注字段的 2 组** |
| D-Gating 因子个数 D | 4 | 4（不变） |
| 活跃阈值 | 0.01 | 0.01（不变，断崖使其不敏感） |
| STG 重要性取值 | 裁剪后的 clamp(μ,0,1) | 原始 μ（`pjm_2025` 后期已修，v2 沿用） |
| 其余训练参数 | 64-32-16、200 轮、批 50、学习率 1e-3、随机划分 8:2、种子 42 | 不变 |

### 两层剥离的具体做法

**第一层：按已知公式剥离，不看残差。**
把 PJM 官方文档写明的公式和电力常识公式列成清单，只要目标字段出现在某条公式里，
该公式涉及的其余字段一律从候选池剔除，**无论它们在当前池子里能达到多少残差**。
依据是文档而不是数据，不需要任何阈值。

清单（来自 `02_class1_identity/known_formulas.csv` 的验算结果）：

| 公式 | 涉及字段 |
|---|---|
| 日前电价三分量分解 | 日前总电价、日前能量价格、日前阻塞价、日前边际损耗价 |
| 实时电价三分量分解 | 实时总电价、实时能量价格、实时阻塞价、实时边际损耗价 |
| 净交换功率账目关系 | 净实际交换、净计划交换、净非计划交换 |
| 总交换功率同式 | 总实际交换、总计划交换、总非计划交换 |
| 分燃料出力求和 | 总发电量、十种燃料的出力 |
| 备用容量构成 | 主用备用总量、同步备用总量、非同步备用 |
| 功率平衡 | 总发电量、计量负荷、总网损、净实际交换 |

**第二层：按数据发现的关系剥离，看残差。**
就是现在 `02d_layered_strip.py` 在做的逐层剥离，门槛保持 0.10 不变。

这样日前总电价的问题不再存在：`system_energy_price_da` 属于官方公式的分量，
第一层就被剔除，轮不到第二层去判残差。

## 目录结构

根目录只放说明与配置，每个阶段固定三样：`说明.md` + `figures/` + `data/`。
上一版的问题是图、CSV、文档混在一起，而实际只看图和文档。

```
pjm_2025_v2/
├── README.md                  本文件
├── rerun_config.json          全部参数
├── 待执行方案.md               分步骤计划与预计耗时
│
├── 01_preprocess/{说明.md, data/}
├── 02_class1_identity/{说明.md, figures/, data/}       两层剥离各剔除了什么
├── 03_screening/{说明.md, figures/, data/}
├── 04_source_location/<no_screening|with_screening>/run_<时间戳>/
│       {总结.md, figures/target_<字段>/, data/}
└── 05_baseline_compare/<rule1|rule2|rule3>/<no_screening|with_screening>/run_<时间戳>/
        {总结.md, figures/, data/}
```

只跑"排除其余关注字段"两组——受关注字段互相推断属于循环论证，
论文主结果本来就在这一支上。
