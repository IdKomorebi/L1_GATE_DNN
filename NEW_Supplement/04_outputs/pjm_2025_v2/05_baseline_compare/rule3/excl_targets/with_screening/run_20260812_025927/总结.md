# rule3 各方法自主定数（excl_targets / with_screening）

## 一、规则

不再统一字段数，让每个方法按自己的判据决定选多少个，然后同时看两件事：**选了几个**和**推得多准**。

| 方法 | 定数规则 |
|---|---|
| DGatingDNN | 门控值 ≥ 0.01（断崖，阈值不敏感） |
| STG | 门控值 ≥ 0.0 |
| LassoNet | λ 路径上，验证损失在最优 5% 以内里最稀疏的点 |
| Lasso | 交叉验证按 1 倍标准误规则选 alpha 后的非零系数 |
| XGBoost | 固定阈值 τ=0.02（12 个目标共用） |
| Pearson | 固定阈值 τ=0.3（12 个目标共用） |

> XGBoost 和 Pearson 的重要性得分是连续的，方法本身回答不了「选多少个」，只能外部给一个固定阈值。这里给的阈值经过调优，但 12 个目标共用同一个值、不做逐目标调整——这正是这条路的缺陷，下面的离散程度一栏可以看出来。

## 二、总体结果

| 方法 | 平均选中数 | 选中数标准差 | 最少–最多 | 平均测试 R² | 帕累托前沿 |
|---|---|---|---|---|---|
| **LassoNet** | 34.3 | 8.3 | 11–43 | 0.8513 | ✓ |
| **STG** | 13.8 | 5.2 | 3–19 | 0.8461 | ✓ |
| **DGatingDNN** | 12.0 | 5.4 | 2–19 | 0.8425 | ✓ |
| XGBoost | 19.1 | 12.9 | 2–39 | 0.8320 |  |
| Pearson | 23.3 | 5.6 | 13–32 | 0.8247 |  |
| Lasso | 14.2 | 11.5 | 1–35 | 0.7643 |  |

帕累托前沿的含义：不存在另一个方法「字段更少且精度更高」。这个判定不需要给两个指标定权重，所以不引入新的人为设定。

## 三、固定阈值方法的问题

| 方法 | 阈值 | 选中数标准差 | 最少–最多 |
|---|---|---|---|
| XGBoost | τ=0.02 | 12.9 | 2–39 |
| Pearson | τ=0.3 | 5.6 | 13–32 |

能自主定数的方法，选中字段数的标准差平均 7.6；用固定阈值的方法平均 9.2。

差别的来源是：能自主定数的方法会随目标的难易自动调整选几个，固定阈值只能一刀切，在容易推的目标上选太多、在难推的目标上选太少。
