# 对隐性推断源的处置与残余风险（pjm_2025_v2）

定位只是中间环节，发布决策关心的是处置之后还能被推到什么程度。本节对定位出的推断源实施处置，记录四个值：

| 记号 | 含义 |
|---|---|
| 全量 R² | 不处置，用全部候选字段推断 |
| 选中 R² | 不处置，只用门控选出的字段推断 |
| 处置后·选中 | 处置这些字段后，再用它们推断 |
| 处置后·全量 | 只处置选出的字段、其余照常发布，用全部字段推断 |

处置强度设得较粗，目的是说明机制而非调参。
