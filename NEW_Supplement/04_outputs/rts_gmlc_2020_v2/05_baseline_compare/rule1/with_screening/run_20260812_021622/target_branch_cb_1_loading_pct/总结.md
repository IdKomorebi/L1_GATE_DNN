# 各方法对比：线路CB-1负载率

## 一、这次比的是什么

- 目标字段：`branch_cb_1_loading_pct`（线路CB-1负载率）
- 候选字段：13 个
- **统一预算 n = 6**，由本文方法的门控断崖自然切出来
- 全部 13 个字段的普通 DNN：R² = 0.8991（能力上限参照）

每个方法按自己的排序取前 n 个字段，统一用同一个普通 DNN 训练测试。

## 二、同预算下的结果

| 方法 | 说明 | 测试 R² |
|---|---|---|
| DGatingDNN ⭐ | 本文方法：可微稀疏门控（NeurIPS 2025） | **0.8835** |
| STG | 随机门控，高斯松弛逼近 L0（ICML 2020） | **0.8803** |
| Pearson | 相关系数排序（只看两两关系） | **0.8654** |
| LassoNet | 神经网络旁挂线性通路的特征级稀疏（JMLR 2021） | **0.8540** |
| Lasso | 线性稀疏（1996） | **0.8522** |
| XGBoost | 树模型特征重要性（2016） | **0.8476** |

> 同预算下最好的是 **DGatingDNN**（R² = 0.8835）。

## 四、各方法的筛选过程

### DGatingDNN

- 门控模型自身的测试 R²：0.8794
- 活跃阈值 0.01，最终活跃字段 6 个
- 过程图 `DGatingDNN/fig_process.png`：每条曲线是一个字段的门控值随训练轮次的变化，左边线性刻度看保留字段的分化，右边对数刻度看被淘汰字段掉到多低
- 逐轮门控值记录在 `DGatingDNN/gate_history.csv`

### STG

- 门控模型自身的测试 R²：0.8874
- 活跃阈值 0.0，最终活跃字段 9 个
- 过程图 `STG/fig_process.png`：每条曲线是一个字段的门控值随训练轮次的变化，左边线性刻度看保留字段的分化，右边对数刻度看被淘汰字段掉到多低
- 逐轮门控值记录在 `STG/gate_history.csv`

### LassoNet

- 它的筛选过程是一条 λ 路径：正则强度从小到大变化，字段被逐个剔除
- 路径共 433 个点，字段数从 0–13 变化
- 记录在 `LassoNet/lambda_path.csv`

### XGBoost / Lasso / Pearson

这三个不存在「逐轮收缩」的过程——它们一次拟合就给出全部字段的重要性排序，选多少个完全由外部指定的 k 决定。各字段得分见各自目录下的 `ranking.csv`。
