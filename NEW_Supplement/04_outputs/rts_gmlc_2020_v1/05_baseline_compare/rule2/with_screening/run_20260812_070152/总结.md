# rule2 老规则总体比较（excl_targets / with_screening）

## 一、规则

按字段数递增，任一方法首次达到全量 DNN 的 95%（或 97%）时的字段数作为统一预算。**预算由最先达标的方法决定**，这条规则天然对该方法有利，结果中如实标出是谁先达标。
