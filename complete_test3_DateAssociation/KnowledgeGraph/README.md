# 知识图谱可视化系统

## 系统概述

这是一个基于NetworkX + PyVis的知识图谱可视化系统，专门用于展示y变量与x变量之间的关联关系。

## 功能特性

### 1. 核心功能
- **以y为中心**: 知识图谱以目标变量(y1-y10)为中心节点
- **三种相关系数**: 支持MI(互信息)、Spearman、Pearson三种关联度方法
- **阈值过滤**: 可设置关联度阈值，过滤弱关联
- **交互式可视化**: 支持节点拖拽、缩放、点击查看详情

### 2. 可视化特性
- **节点颜色**: 
  - 红色节点: 目标变量(y1-y10)
  - 青色节点: 特征变量(x1-x10)
- **边的颜色和粗细**: 表示关联强度
  - 红色: 强关联 (≥0.7)
  - 橙色: 中等关联 (≥0.5)
  - 黄色: 弱关联 (≥0.3)
  - 浅黄色: 很弱关联 (<0.3)
- **边的粗细**: 与关联强度成正比

### 3. 布局优化
- **y节点**: 排列在中心圆形区域
- **x节点**: 使用螺旋分布，避免整行/整列排列
- **物理引擎**: 支持节点间的引力和斥力

## 文件说明

### 生成的文件
- `knowledge_graph_mi.html`: MI方法的知识图谱
- `knowledge_graph_spearman.html`: Spearman方法的知识图谱
- `knowledge_graph_pearson.html`: Pearson方法的知识图谱
- `dashboard.html`: 交互式仪表板

### 使用方法

1. **直接查看**: 双击HTML文件在浏览器中打开
2. **交互操作**:
   - 拖拽节点调整位置
   - 滚轮缩放图谱
   - 点击边查看关联度详情
   - 悬停查看节点信息

## 技术实现

### 依赖库
- `pandas`: 数据处理
- `networkx`: 图结构处理
- `pyvis`: 交互式可视化
- `numpy`: 数值计算

### 核心算法
1. **数据过滤**: 根据方法和阈值过滤关联度数据
2. **图构建**: 使用NetworkX构建无向图
3. **布局优化**: 自定义布局算法避免规整排列
4. **可视化**: 使用PyVis生成交互式HTML

## 参数说明

### 阈值设置
- `threshold=0.1`: 默认关联度阈值
- 低于此值的边将被过滤
- 可根据需要调整阈值

### 方法选择
- `MI`: 互信息，适合非线性关系
- `Spearman`: 等级相关系数，适合单调关系
- `Pearson`: 线性相关系数，适合线性关系

## 使用示例

```python
from FinalKnowledgeGraphSystem import FinalKnowledgeGraphSystem

# 创建系统
kg_system = FinalKnowledgeGraphSystem(
    data_file="DataAnalyze/correlation_summary_RawSample1.csv",
    threshold=0.1
)

# 生成所有可视化
output_dir = kg_system.generate_all_visualizations()
```

## 注意事项

1. **数据格式**: 需要包含method、y、weight、x1-x10等列
2. **浏览器兼容**: 建议使用Chrome、Firefox等现代浏览器
3. **性能**: 大量节点时可能影响渲染性能
4. **阈值**: 过低的阈值可能产生过多边，影响可读性

## 故障排除

### 常见问题
1. **文件无法打开**: 检查浏览器是否支持HTML5
2. **图谱空白**: 检查数据文件和阈值设置
3. **性能问题**: 降低阈值或减少节点数量

### 调试方法
1. 检查控制台输出
2. 验证数据文件格式
3. 测试不同阈值设置
